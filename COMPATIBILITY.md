Sources: pi 1.0.4 (tag v1.0.4, commit 7c10bd4337495ee613f2224843ecdf349b80d1df, `vendor/pi-src`); the first phases read commit f10993bc, a main snapshot after 1.0.4 (see `thoughts/shared/research/2026-10-07_pi-sources-addendum.md`) and the research R2. Status: planned / partial / done / not planned + reason. "Phase item" is a plan item id where the plan has one (B1-B12, D1-D8, A-series) and a phase letter otherwise (C, E ... O); item ids are assigned when the phase is detailed. Phase A delivered documents and probes; later phases mark their rows done.

Decision D3: the pi `bash` tool is named `bash` and runs `vsh -c` (AmigaDOS Shell fallback). `shell` in older plan text is superseded.

Rows per group (207 total, counted from the tables: the lines starting with `|` minus each table's header and `|---` separator, 235 - 2 x 15 = 205, plus the two rows added for Q3 and Q11): pi-ai 32; pi-agent-core 6; pi-coding-agent 15; pi-tui 32; sessions 27; tools 7; extensions 20; skills 4; prompt templates 2; themes 3; RPC 12; JSON mode 1; SDK 1; MCP 28; pi-modes 17.
